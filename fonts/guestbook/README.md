# Guestbook Sans

A locally hosted, renamed web subset of **IBM Plex Sans SC**, Regular (400) and Medium (500), from IBM’s official `@ibm/plex-sans-sc@1.1.0` package. The npm archive was checked against its published SHA-512 integrity value.

Source: https://github.com/IBM/plex/tree/master/packages/plex-sans-sc
Package: https://www.npmjs.com/package/@ibm/plex-sans-sc/v/1.1.0

The derivative is renamed **Guestbook Sans**; original copyright and license metadata remain embedded. The complete SIL Open Font License is in [OFL.txt](OFL.txt).

The subset contains first-level GB2312 Chinese characters, the guestbook interface characters, common Latin and punctuation supported by the source. Characters not included fall back to Ruoxuan Sans or the system sans font. Manifest entries record each exact WOFF2 resource, weight, size and SHA-256. Visitors load the fonts from this site, without contacting a third-party font service.
