# Ruoxuan Sans web subset

This local WOFF2 is a renamed web subset of [Noto Sans SC Variable](https://github.com/notofonts/noto-cjk/blob/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf), distributed under the SIL Open Font License in [OFL.txt](OFL.txt).

The derivative is named **Ruoxuan Sans**. Original copyright and license metadata are retained in the font. It includes common first-level GB2312 Chinese characters, the site's interface/name/language characters, Latin, Cyrillic, kana and punctuation where the source provides them. Missing characters use the system sans fallback. The variable weight axis is limited to 300–600.

The font is hosted by this site. Visitors do not contact an external font service. The build checks its content-hashed filename and packages the original WOFF2 bytes; `manifest.json` records the exact resource.
